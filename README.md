# ResQMeal — Week 4

## Files
- `index.html` — accessible page structure
- `style.css` — responsive styles and accessibility utilities
- `script.js` — navigation, listing filters and modal interactions
- `Week4_Performance_Accessibility_Report.md` — implementation notes and testing checklist

## Run locally
Keep all three source files in one folder. Open `index.html` in a browser or use VS Code Live Server.

## Before submission
Run Lighthouse on mobile and desktop, scan with axe or WAVE, complete the report's actual-results column, and attach screenshots. Do not invent scores or user feedback.
